- AutoClean Agents

-> Can a multi-agent system replicate the data cleaning decisions a data scientist makes manually?

A research project exploring agentic AI for automated data quality assessment and correction, applied to real-world railway punctuality data (SNCF TGV dataset).

## Status
Work in progress

## Motivation
During an internship working with railway operational data, a significant portion of the analysis time was spent on manual data cleaning and detecting missing values, fixing type inconsistencies, handling outliers. This project asks: can a pipeline of collaborative AI agents automate these decisions?
